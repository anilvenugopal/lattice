## The screen

- **The rail** is the column of icons on the far left. Each icon is an app or
  an area: Home at the top, Administration and your Account at the bottom.
  Hover over an icon to see its name.
- **The sidebar** lists the pages of the area you are in. Areas with a single
  page have no sidebar.
- **The top bar** shows where you are as breadcrumbs (Grids / Items /
  IT-0042). Choose a breadcrumb to go back up.
- **The status bar** at the bottom shows the environment (for example
  DEVELOPMENT or PRODUCTION), who you are signed in as, and your roles.

You only see the areas and pages your roles allow.

## Home

The home page shows counts from the apps you use, such as "Open work items"
or "Assigned to me". Choose a count to open that list. Administrators also see
recent activity.

## Ctrl+J: search and jump

Press **Ctrl J** (**⌘ J** on a Mac), or choose the search box in the top
bar, and start typing. One search covers:

- **pages**: jump to any page by name;
- **records** in the lists that support it, such as work items;
- **help** topics;
- **commands**, such as "Theme: Dark" or "Sign out".

| Keys | Do |
|---|---|
| ↑ ↓ | Move through the results. The pane on the right previews the highlighted one |
| Tab, Shift+Tab | Show only one source (Pages, a list, Help, Commands), or the next one |
| Enter | Open the result, or run the command |
| Esc | Close |

You can also choose a source on the left to see only its results.

## Help

- **F1** opens the help for the page you are on. So does **Help for this
  page** in the help menu (the ⓘ icon in the top bar).
- **All help** in the same menu opens the Help centre, with every app's help.
- The search box at the top of every help page searches all help topics.

## Keyboard shortcuts

Press **?** anywhere (outside a text box) to see them all.

| Keys | Do |
|---|---|
| Ctrl J | Search and jump |
| F1 | Help for this page |
| ? | Show the shortcuts |
| / | Search the list on this page |
| ↑ ↓ or J K | Move between rows in a list |
| Space or X | Select the row |
| Enter | Open the row |
| Ctrl A | Select every row on the page |
| Esc | Close the side panel, then clear the selection |
