## Attaching files

Every record page with an **Attachments** panel takes files: drop them on the
panel, or select **choose**. Each file may be up to the size the panel shows
(25 MB unless your site says otherwise), and only common document and image
types are accepted.

- **Select a file's name** to download it.
- **Open** shows images and PDFs in a new tab.
- **Remove** deletes a file you attached. Administrators can remove anyone's.

You see a record's files only when you can open the record itself. People who
follow the record are told when a file is added (see
[Notifications](notifications.md)).

## Choosing a folder on a shared drive

Some forms ask for a folder on a shared drive, such as where a claim's documents
live. Select **Browse…**:

- select a folder to go into it, and the path at the top to go back up;
- **Create** makes a new folder where you are;
- **Choose this folder** picks the one you are in.

**Clear** removes the choice. You need the **Browse shared folders** permission,
which editors have.
