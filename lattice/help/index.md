Lattice is the platform this application runs on. It provides sign-in, the
navigation around every page, Ctrl+J search, your preferences, and the lists
and forms every app shares.

> [!TIP]
> Press **F1** on any page to open the help for that page, and **Ctrl J** to
> search pages, records, commands and help from anywhere.

## For developers

The [Developer guide](developer/index.md) explains how Lattice works and how
to build, run and extend apps on it. Start with the
[Overview](developer/overview.md), then [Getting started](developer/getting-started/index.md).
